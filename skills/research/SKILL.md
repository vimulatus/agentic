name: research
description: Investigate a question against primary sources and write the findings to a Markdown file in the repo. Use when Vasu wants a topic researched or docs read in the background.
---

Spawn a `general-purpose` subagent with the Agent tool, so you keep working while it reads.

Its brief:

1. Investigate the question against **primary sources**: official docs, source code, specs, first-party APIs. Follow every claim back to the source that owns it.
2. Write the findings to one Markdown file, with each claim's source next to it.
3. Save it where the repo keeps such notes. No convention: pick a sensible place and say where.

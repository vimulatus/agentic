# L3 — dispatch

One open ticket. Pick the approach.

| The ticket needs | Reach for |
|---|---|
| an external fact | `research`, in the background |
| Vasu's taste, or a domain rule | `grilling` |
| to be seen before it is decided | `prototype` |
| code | `red-green`, then the `dev` subagent |
| proof it works in the running app | `browser-evidence` |

- Work the slices in map order. The ticket to take is the first open one in the first slice with open tickets.
- Assign the ticket to yourself before you work it. The assignment is the claim.
- One ticket per session. Research is the exception — it runs in parallel.
- Close the ticket with its answer in a comment, and add the decision to the map.
- When a decision from the code overturns a later slice's tickets, rewrite those tickets before you take them.
